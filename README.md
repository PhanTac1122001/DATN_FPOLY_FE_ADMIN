# LMS Portal FE (User)

Frontend Next.js cho LMS Portal — portal sinh viên (extracted-portal UI).

## Stack

- Next.js 16, React 19, Tailwind CSS v4, TypeScript
- pnpm (`pnpm@10.12.1`)
- TanStack Query, Zustand, React Hook Form + Zod

## Getting started

```bash
pnpm install
pnpm dev
```

Mở [http://localhost:3000](http://localhost:3000).

## Scripts

```bash
pnpm run type-check
pnpm run lint:check
pnpm run build
```
